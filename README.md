# Finalidade do repositório

Este repositório está reservado para o serviço `ai-accessibility` da organização Solaria. Pelo nome, o serviço deve tratar de acessibilidade assistida por IA (ex: leitura de tela, contraste, alternativas textuais) para os produtos da organização — mas isso ainda não foi confirmado em código, já que o repositório contém apenas o scaffold inicial (`LICENSE`, `.editorconfig`, `.gitattributes`, `.gitignore`, template de Pull Request). Nenhuma linha de código de aplicação foi commitada até o momento.
